# Recovered Components

This historical ledger records concepts retained because they remain defensible after reconstruction:

- translation is a constrained multidimensional trade-off rather than a one-axis optimization;
- proteostasis capacity restricts which translation strategies are viable;
- damage depends on expression, site, and substitution identity;
- finite rescue capacity can create nonlinear stability boundaries;
- a minimal fold model is useful for intuition when its phase portrait is stated correctly;
- theory should generate discriminating perturbation experiments and multi-proxy comparisons.

Recovery does not preserve old derivations, numerical estimates, datasets, or rhetoric. Each retained component is redefined in the current theory files.
