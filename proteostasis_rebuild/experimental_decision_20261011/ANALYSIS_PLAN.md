# Prospective analysis and specimen contract

Status: design complete; no new wet-lab performed. This document specifies future analysis; no estimator or simulation was run. Protocol §5 defines Y, D and Theta and is authoritative. The report's public-data verdict remains final.

## Estimation, uncertainty and independent limits

Use the same six chase times in every cell. Compute trapezoidal Y for each culture without extrapolation. The baseline specimen is QC, not part of the chase integral. For each complete day/lineage block, form the 16-term Nva Theta contrast using cell means; Val cells are reserved for the secondary contrast. Each nonzero coefficient has magnitude one. Report every cell mean, D(HIGH/LOW,ADD/EMPTY), the ADD interaction, the EMPTY interaction and corrected Theta with uncertainty. A cancellation between large opposite control effects is not proof of specificity.

Primary estimate is the mean block contrast, with two-sided 95% Student-t CI across independent complete block contrasts. Pilot checks the suitability of this scale/distribution using assay data; if robust alternatives are required, freeze one before confirmation, never choose it using confirmatory sign. Block/lineage clustering must be respected; confirmation balances construction lineages across days rather than treating technical splits as n. If repeated lineage effects dominate, use a prespecified hierarchical/block analysis and increase independent lineages at freeze; three pilot lineages cannot establish universality. Retain blinded assay duplicates only for precision and recovery estimation. No arbitrary pseudocounts, top-quintile labels, predictive-model comparisons or feature tuning are involved.

Propagate calibration, IP recovery and precursor-enrichment uncertainty into each culture Y by analytical error propagation with covariance for shared standards, then include it in block-contrast uncertainty. Report biological-only and calibration-inclusive intervals; G5 uses the wider interval. Calibration uncertainty common to all blocks does not shrink with n. If it dominates the chosen effect scale, G4 fails. No imputation of below-quantification or missing time points as zero. Report censoring intervals for bounded measurements; if the resulting conservative Theta interval cannot establish the same G5 decision, classify inconclusive. For an objectively documented technical failure, repeat the failed assay from retained material while blind; if irrecoverable, report the cell and block missing. Replacement cultures are permitted only under the frozen non-outcome-dependent failure rule and must replace a complete balanced block. Report all attempted blocks and sensitivity bounds, not selective complete-case success.

Set delta, the smallest scientifically important reduction in captured-cohort-fraction·min, **independently of observed pilot Theta** using achievable quantification and biological relevance. Specify a separate planning distance d from the G5 boundary and justify it without taking the favorable pilot effect estimate. Pilot estimates the variance of the block contrast, not the effect to power against. Let sigma_U be an upper confidence bound on its SD (under justified approximate normality, use a chi-square upper variance bound; otherwise obtain more pilot blocks). Initial block count: n >= ((z_0.975 + z_0.90) sigma_U / d)^2, rounded up and refined using a t-based power calculation at two-sided alpha .05, 90% power. This is a formula, not a fabricated sample size. Also require CI precision capable of distinguishing ±delta around zero and adequate precision for G1/G2 equivalence gates. The largest required n governs. State total confirmation cultures = 24n plus validation/QC cultures. Three pilot blocks yield an unstable variance estimate; if its upper bound requires unaffordable n, stop rather than assert power. No simulated data are needed.

Freeze numerical bounds for growth-rate difference, viable-fraction loss, protein-specific synthesis ratio, Nva/Val error-frequency difference, relevant spectrum components, capture recovery, background, mass balance, precursor clearance, detection/quantification limits, reporter perturbation, and functional capacity increment in FREEZE_RECORD_TEMPLATE.tsv. Set equivalence margins from assay validation plus scientifically acceptable departures, **not** from whichever differences happen to appear small. Require simultaneous 95% CIs (Bonferroni over the locked G2 family) entirely inside each margin; nonsignificant differences are not equivalence. Compare HIGH vs LOW within every exposure/allele/cassette for growth, synthesis and errors; compare ED/REP at the selected exposure for growth/synthesis matching, and REP exposures vs NONE for toxicity. Off-target spectrum comparisons are restricted to an analytically validated prespecified panel, with unmeasured errors acknowledged. Cannot pass a spectrum-equivalence gate by dropping a detected substitution after seeing differences.

G1 asks whether ED's exposure error increment exceeds REP's and whether ED NVA exceeds ED NONE. G2 demands functional machine increase and separation from measured incidence/synthesis changes. G5 tests one primary Nva contrast; the Val contrast and all stress/aggregate analyses are secondary, reported with intervals and a clearly enumerated Holm family if inferential p-values are supplied. They cannot rescue primary failure. Total activity and pulse-labeled abundance are separately measurable. Pulse-cohort functional yield is UNIDENTIFIABLE without an independent pulse-cohort activity assay or a validated conditional synthesis-stop preserving physiology: unlabeled newly synthesized reporter after the pulse also contributes to total activity, and error variants may differ in specific activity. Do not infer pulse-cohort active counts or yield by dividing total activity by pulse-end production. G6 is conjunctive: first establish pulse-cohort functional identifiability and validated error-dependent specific activity, then require an independently supported increase in new-native yield plus acceptable competing-loss bounds; do not equate absence of a significant degradation change with its exclusion. Without that independent validation, report total activity and labeled abundance separately and association relief only, with no new-native yield claim. RpoS/RpoH timing is descriptive; no feedback mediation estimate is claimed.

## Pilot and confirmation separation

The assay/dose calibration subphase may use screening cultures beyond the 72 full-grid pilot cultures. Keep their manifest separate as PILOT_CAL; log every condition and excluded attempt. Use only growth/synthesis/error/functional-capacity validation to select doses. The full-grid pilot then estimates variance and validates the six-point burden assay. Pilot burden results remain exploratory and are excluded from confirmation. No true occupied-site-time endpoint becomes identifiable merely because G3 passes; it remains a different, unmeasured construct.

Before confirmation, fill and sign every freeze field; hash protocol, analysis plan, source list, finalized sample sheet, randomization key and analysis code. Record timestamp and analysts with prior pilot access. Start entirely new cultures after this time. Lock n, inclusion rules and one analysis; no interim stopping for significance. If a gate fails in confirmation, retain all results and label the primary noninterpretable/inconclusive as specified. Any redesigned experiment would be new exploratory work, not a rescue within this task.

## Specimen and metadata schema

SAMPLE_SHEET_TEMPLATE.tsv is an unrandomized collection template, **not observations or a frozen allocation**. It includes three pilot blocks P01–P03 and one confirmation pattern C_BLOCK_REPEAT. Repeat the latter for the locked n with fresh globally unique IDs and balanced lineage IDs; do not count this placeholder as collected data. There are 24 cultures × 7 times = 168 parent rows per block; 672 rows in this template. Same culture_id across its seven rows denotes repeated sampling. B0 is pre-exposure −1 min with chase_min=NA; C00–C40 are exposure 25–65 min. LOW dose is zero IPTG; NONE dose is zero added Nva/Val, despite basal Val in the shared medium.

Required factor fields: phase, block_id, lineage_id, culture_id, specimen_id, allele (ED/REP), exposure (NONE/NVA/VAL), cassette (ADD/EMPTY), inducer_level (LOW/HIGH), reporter, time_id, planned_exposure_min, planned_chase_min and assay_bundle. Shared fields medium_id, SOP_version, temperature_C, amino_acid_background, pulse_start_min, pulse_end_min and sample_role prevent implicit changes. Allocation_seed, blinded_id and run_order must be filled before collection, not derived from outcomes.

Each specimen produces child records `specimen_id:INPUT`, `:DNAK_IP`, `:ISOTYPE_IP`, `:SOLUBLE`, `:PELLET`, `:ACTIVITY`, `:STRESS`. Child data require child_id, parent specimen_id, assay, aliquot_volume, input_cell_equivalents, collection/quench timestamp, storage/processing interval, extraction_batch, instrument_batch, raw_file, sha256, SOP_version, standards_lot, operator, blinded_qc_decision and reason. Activity and protein aliquots are distinct but paired. Collection totals and minimum input are set by validated assay requirements before inoculation. Blank, pooled-reference and ATP-omission controls use independent QC IDs linked to their batch; they are not extra factorial cultures. DnaK/isotype controls are matched within every culture/time.

Long-form peptide data require peptide_sequence, protein_accession, substitution, site, isotope_state, modification, localization_score, FDR, peak_area, response_factor, precursor_enrichment, amount, uncertainty, LOD, LOQ and censoring_flag. Activity data require raw_signal, blank, dilution, linear_range, calibration, matrix_spike_recovery and activity_equivalents; mass balance requires total/soluble/pellet recovery and cell counts. Error counts and cognate denominators remain available, not only ratios.

`PENDING_*` fields deliberately indicate unknown measured or calibration values; `NA` means logically inapplicable. Never replace unknowns with zero. Before confirmation, every PENDING_LOCK/PENDING_ALLOCATION field must be resolved; before data analysis every PENDING_MEASUREMENT/PENDING_QC field must be measured or carry an explicit missingness reason. The offline checker checks template structural completeness, not assay success or confirmation readiness.
