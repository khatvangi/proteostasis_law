# Bounded exploratory proxy protocol

Written 2026-10-12 before this run reads either raw outcome table or existing outcome reports. This folder already contains an earlier dossier. This is a prospective analysis specification within an exploratory reanalysis, NOT genuine preregistration or independent confirmation. Historical GATE3_STATUS.md remains VOID and untouched.

## Frozen scope and eligibility
Read only the two archived Pranjic proteinGroups tables and metadata in experimental_decision_20261011. Write only inside this folder. No paper rewriting, wet lab, universal threshold, or inferential p-values treating proteins as biological replicates.
Exclude Reverse or Potential contaminant flagged rows and REV__/CON__ accessions; exclude Only identified by site rows. Ambiguity means missing or multiple semicolon-separated Protein IDs, Number of proteins other than 1, or duplicate exact accession within a fraction (exclude all duplicates). Join fractions by exact Protein IDs, never gene names. Do not resolve ambiguous groups post hoc.
Primary universe: eligible exact accessions with finite, strictly positive iBAQ for all four labels A-D in every ED and ED Delta clpB Nva/blank arm, in BOTH fractions (32 measurements). No imputation, pseudocounts, or outlier exclusion. Report exclusion and coverage counts, including retained signal fractions.

## Estimand and normalization
For a fixed matched universe S, independently normalize each fraction and each sample: share(i,f,c,r)=iBAQ(i,f,c,r)/sum(j in S)iBAQ(j,f,c,r). Thus denominator is the same matched complete-case protein set, separately summed in every sample. Average shares over labels within each condition and fraction, then Y(i,c)=log2(mean aggregate share / mean proteome share). Do not average log ratios or pool raw intensities; do not pair labels across fractions.
Primary interaction I_Nva=(Y(ED Delta clpB,Nva)-Y(ED Delta clpB,blank))-(Y(ED,Nva)-Y(ED,blank)). Positive means a larger Nva-associated relative redistribution toward the insoluble fraction in the deletion genotype. Compositional closure precludes a bulk-mass interpretation.
Report n, median, 25th/75th percentiles (linear interpolation), strict positive fraction (zeros not positive), minimum and maximum. Proteins are correlated descriptive units, not biological n. No confidence intervals or p-values across proteins.

## Fixed secondary and controls
Val versus blank uses the identical formula on its own matched complete-positive universe. Specificity additionally compares Nva and Val interactions on a common universe positive in all six conditions and both fractions; report I_Nva-I_Val and both interactions there.
A/B versus C/D negative control: within each treatment (blank, Nva, Val), replace treatment contrast by Y(AB)-Y(CD), then difference deletion minus ED. Use the primary universe for blank/Nva, secondary universe for Val. Also report primary interactions independently computed using AB only and CD only and their difference. These are label-split diagnostics, not randomized null tests, and labels need not be paired across fractions.
Leave-one-label-out: keep the full primary universe and normalization fixed; omit A, B, C, D separately from aggregate averaging only, then proteome averaging only (8 checks). Also omit the same label in both fractions (4 sensitivity checks, NOT evidence of pairing). Report distributions and per-protein sign agreement with full primary. No re-selection based on robustness outcomes.

## QC, gates, provenance, stopping
Verify required metadata columns/labels, raw schema, archive SHA256 against metadata, finite positive denominators, unique joins, complete-case coverage and sum-to-one shares. Report raw/filtered counts, missing/nonpositive per sample, and retained iBAQ fractions relative to all eligible positive measurements. If a required schema/hash/empty-universe gate fails, report blockers rather than invent estimates. Unknown fraction pairing and biological independence block replicate-level inference but not the descriptive estimand. No minimum coverage threshold chosen after outcomes.
Save PROXY_ANALYSIS.py, protein-level outputs, distribution summaries, QC, GATES.tsv, source hashes, protocol hash/read receipt, tests and final report. Tests must cover filtering, contrast sign, compositional scale invariance, independent fraction averaging and actual output reconstruction. SHA256 manifest covers results and code (excluding itself).

## Interpretation fixed before outcomes
Metric measures relative redistribution in a detected complete-case subset, NOT bulk aggregate mass, actual mistranslation burden, chaperone occupied site-time, machine capacity or quantitative headroom. Interpret beside independent Ruan 2008 (10.1073/pnas.0809179105), Pranjic 2024 (10.1016/j.ijbiomac.2024.130068; same study as archives, not independent replication), Martens & Hilser 2025 preprint (10.1101/2025.06.25.661590; production rather than mistranslation), McDonald 2025 (10.1093/nar/gkaf428; different routes), Fauvet 2021 (10.3389/fmolb.2021.653073; confront wrong-signed model point estimate), and FoldEco prior art. Separate positive conditional mathematics, biological proxy evidence, and still unidentifiable quantitative headroom. Make no unfounded novelty claim.
